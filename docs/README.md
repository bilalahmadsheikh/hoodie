# How this hoodie was built, and how to make the next one

These docs explain the whole pipeline behind the GIK 13 14 hoodie: reference photos
in, then a realistic 3D model, a shareable 3D viewer, print-ready artwork, and a
Canva tech pack that a hoodie maker can produce from. Everything is driven by
`build_hoodie.py` and the scripts in `tools/`, so the next hoodie is mostly a matter
of swapping artwork and changing a few settings.
